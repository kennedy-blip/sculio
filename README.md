# QR Code Generator

A simple web-based QR code generator built with plain HTML, CSS, and JavaScript. It uses the lightweight **QRCode.js** library (served via CDN) to create QR codes for any text or URL.

## Features
- Input any text or URL and generate a QR code instantly.
- Adjustable QR code size.
- No build step or server required – just open `index.html` in a browser.

## How to Use
1. Open `index.html` in a modern web browser.
2. Enter the text or URL you want to encode.
3. (Optional) Change the size in pixels.
4. Click **Generate QR** – the code appears below the button.

## Local Development
The project consists of only two files:
- `index.html` – the web page and QR generation script.
- `README.md` – this documentation.

You can run it locally without any tooling:
```bash
# From the project folder
start index.html   # Windows (or open with your browser)
```
